# Yoga-Heal-Hub

![Yoga-Heal-Hub preview](screenshot.png)

Yoga-Heal-Hub is a responsive multi-page yoga and wellness website for exploring classes, instructors, contact information, and practical wellness articles.

## Features

- Responsive fixed header with desktop dropdown and mobile navigation
- Home, About, Classes, Instructors, Blog, Blog Post, and Contact pages
- Local image assets with meaningful names and accessible alt text
- Dynamic blog routes, route-aware scroll reset, and floating back-to-top control
- Icon-only social and support links in the footer

## Tech stack

- React and Vite
- React Router DOM
- styled-components
- React Icons

## Getting started

```bash
npm install
npm run dev
```

Create a production build with `npm run build`. Preview it locally with `npm run preview`.

## Deployment

The project is deployed at [https://a2rp.github.io/yoga-heal-hub/](https://a2rp.github.io/yoga-heal-hub/).
